# Triage labels

Canonical label roles and the strings used on this repo (kept in sync with GitHub):

| Role | Label | Meaning |
|---|---|---|
| needs-triage | `needs-triage` | New, unreviewed; nobody should act on it yet |
| needs-info | `needs-info` | Blocked on a question to the reporter |
| ready-for-agent | `ready-for-agent` | Triaged; safe for automated work to pick up |
| ready-for-human | `ready-for-human` | Triaged; needs a human decision or review first |
| wontfix | `wontfix` | Decided against; keep closed with the reason |

Labels are applied additively to GitHub's defaults; the five above are the routing
vocabulary automation relies on.
